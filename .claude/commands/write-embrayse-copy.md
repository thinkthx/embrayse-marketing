# Write Embrayse Copy

You are writing marketing copy for Embrayse. Before writing, load the brand context by reading `.claude/commands/embrayse-brand-narrative.md`. Follow it exactly.

## Your task

Write copy for: $ARGUMENTS

If no specific request was given, ask what copy is needed.

## Writing rules

**Voice & tone:**
- Warm, direct, confident, human. Never clinical or corporate.
- Acknowledge the real difficulty of aged care work — then resolve anxiety with reassurance, not alarm.
- Australian English throughout: "aged care" not "senior living", "facilities" not "communities", "residents" not "patients".
- Do not be dismissive of staff effort. Pain points should feel empathetic, not cynical.

**Structure:**
- Lead with the reader's problem or desire, not with Embrayse.
- One idea per section. One CTA per section.
- Short paragraphs. Conversational rhythm. Break up walls of text.
- Use concrete details over vague claims: "45+ facilities", "$7/bed/month", "60-day full refund" — specifics build trust.

**Messaging hierarchy (use as needed, in this priority):**
1. Simplicity — staff actually want to use it, minimal training, simpler than paper
2. Compliance confidence — Standard 6 readiness, audit-ready, dietary safety
3. Risk mitigation — allergy/texture incidents prevented, nothing falls through cracks
4. Operational efficiency — less manual work, fewer errors, time saved
5. Integrations — works with their existing care software at no extra cost
6. No-risk commitment — no lock-in, 60-day refund, onsite implementation included

**What to avoid:**
- Jargon, buzzwords, or empty superlatives ("revolutionary", "cutting-edge", "best-in-class")
- Feature dumps without connecting to a real human benefit
- Pressure tactics or fear-mongering about compliance
- Generic SaaS language that could apply to any product
- Overselling — let the product's simplicity speak for itself

## Output format

- Provide the copy ready to use (not wrapped in explanations unless the user asks)
- If writing for HTML, include semantic markup
- If multiple options make sense, offer 2-3 variants with a brief note on the angle each takes
- Flag if anything in the request conflicts with the brand narrative
