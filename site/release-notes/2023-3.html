Release 2023.3 – IDDSI colours and codes, and other improvements

Embrayse has been busy implementing a number of targeted improvements, some of which you have already seen over the past few months. Here is an overview of all the changes since the last release.

IDDSI Colours and Codes

The biggest change you will notice in the user interface is the introduction of badges for IDDSI food and drink textures. Previously we displayed this information in full text format, for example L5 Minced & Moist. Instead, you will now see badges as shown in the screenshots below. This achieves two things. Firstly, it brings the interface more in line with the IDDSI Framework standards. Secondly, it makes it easier to spot texture modification requirements and saves space, especially on the Prep report.

Removing Photos

Both resident and menu items can now have their images removed, if they are no longer relevant. Previously if a photo was already added, it could only be replaced with a different one, but not removed.

Security and Performance Upgrade

In the background, we have been making a major upgrade to our infrastructure and codebase. While there is no functionality change, this upgrade makes Embrayse more secure and more performant than ever. Additionally, it puts us in a good place to build and release more features in 2024 and beyond.

Other Improvements and Bug Fixes

  • Menu items on the ordering screen and Prep Report now appear in the same order as the menu planner.
  • Added Pork, Tomato, and Strawberry as allergens.
  • Added Dysphagia as a medical condition.
  • Preferred Name now displays before Full Name everywhere including the resident list and Prep report.
  • Fixed: Easy to Chew (Level 7) is not correctly synchronised from PCS.
  • Fixed: Birthday notice on resident list is not correctly aligned on Safari browsers.
