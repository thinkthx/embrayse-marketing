Release 2025.3 – Accessibility and Quality of Life Improvements

Over the past few months, we have continually made improvements to Embrayse, culminating in our most recent accessibility improvements release. Here is a recap of all the changes.

Accessibility Improvements

As part of our ongoing commitment to equal access to our software, we have shipped platform-wide accessibility improvements, bringing Embrayse largely in line with Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. Highlights include better colour contrast for all text and icons, screen reader labels for all interactive elements, and improved keyboard focus for all interactive elements.

Prep Report Expand/Collapse All

You can now quickly expand all orders on the prep report, making navigation of the list quicker.

Update Banner

We'll now give you a heads-up when a new version of Embrayse is available. If your browser tab has been open for a while, you'll see a banner at the top. Refresh to load the latest features and fixes.

Other Improvements and Bug Fixes

  • When copying a menu, you can now optionally disable copying of the menu title. This is useful, for example, when you want to copy the same breakfast items across many weeks, but want to leave the target menu titles unchanged.
  • The "You have no permissions" page now displays the name and email of the logged-in user, and gives you the option to log out.
  • The notifications dropdown list now always shows the latest changes at the top, regardless of whether they've been read or not.
  • Improved the loading performance of the Plan > All Items screen.
  • Improved logging for the customer facing APIs.
  • The Menu Copy window now picks a better default starting and ending week when using the Repeat function.
  • Fixed: Meal notes larger than 200 characters caused an error. The textbox is now limited to 200 characters.
  • Fixed: On the Plan page, the Clear button and Title were enabled for closed weeks. These have now been disabled.
  • Fixed: The Settings > Users page did not correctly handle more than 100 users in the organisation.
