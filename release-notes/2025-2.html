What's new

Release 2025.2 – All About Menus

The latest Embrayse release focuses on enhancing menu management and simplifying communication with residents and stakeholders.

Printing Menus

While TVs and tablets remain central to enhancing the dining experience, printed menus give you an additional method to improve communication and meet compliance requirements. This new functionality allows you to quickly print beautifully formatted weekly menus, in A4 or A3 sizes, suitable for noticeboards or tables. You can optionally include IDDSI texture levels, and control which menu items are shown.

Menu CSV Export

While we recommend providing digital access for menu reviews, we now offer the option to export menus as CSV spreadsheets to facilitate offline reviews by dietitians and other stakeholders. The exported menu includes the date and meal service, meal category (Main, Side, Dessert, or Beverage), meal name, and available textures.

Menu Titles

You can now assign titles to menus, indicating details like season and week number, making weekly menus easier to identify. When copying a menu, its title is duplicated along with all menu items.

Advanced Menu Copy

Copying menus for your cycling menus is now easier than ever. The new repeat feature allows you to easily copy menus on a fixed cycle (e.g. every 4 weeks) for any number of repetitions to cover an entire season. Alternatively you can use the familiar Individual Week interface, where you can now load additional weeks and copy further into the future.

Other Improvements and Bug Fixes

  • Improved the error message when an incorrect TV menu code has been entered.
  • Security improvements.
  • Fixed: Clicking the "clear" button in the week selector dropdown causes an error.
  • Fixed: Name search on prep report does not always work on iPad.
